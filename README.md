# ميزانية العائلة

موقع ميزانية لعائلة دخلها غير ثابت: كل إيراد يدخل **الاحتياطي**، والبيت يعيش على **حصة شهرية ثابتة**، والمصروف اليومي يمشي بـ **ظروف أسبوعية**. البيانات مشتركة بين جوالين بكلمة سر وحدة للعائلة، ومحفوظة في Netlify Blobs.

## التشغيل على Netlify (مرة وحدة)

1. في Netlify: **Add new site ← Import an existing project ← GitHub** واختاروا هذا المستودع. الإعدادات تنقرأ تلقائياً من `netlify.toml`، فاضغطوا **Deploy**.
2. **Site configuration ← Environment variables ← Add a variable**:
   - الاسم: `FAMILY_PASSWORD`
   - القيمة: كلمة سر قوية للعائلة، 12 حرف أو أكثر.
3. **Deploys ← Trigger deploy ← Deploy site** عشان تشتغل كلمة السر.
4. افتحوا رابط الموقع من الجوالين، اكتبوا كلمة السر، وكمّلوا خطوة «نبدأ» من جوال واحد بس.
5. أضيفوه على الشاشة الرئيسية:
   - آيفون: زر المشاركة ← **Add to Home Screen**.
   - أندرويد: القائمة ← **Install app** أو **Add to Home screen**.

## الملفات

| الملف | الدور |
|---|---|
| `src/app.html` | الصفحة كلها (نفس صفحة النموذج التجريبي) |
| `src/build.py` | يبني `public/index.html` من `src/app.html` بوضع البيانات المشتركة |
| `public/` | اللي ينرفع: الصفحة، الأيقونات، ملف التثبيت، وملف العمل بدون نت |
| `netlify/functions/state.mjs` | يحفظ ويرجّع البيانات المشتركة، ويتأكد من كلمة السر |
| `test/` | سيرفر محلي واختبار تزامن جوالين |

بعد أي تعديل على `src/app.html`: شغّلوا `python3 src/build.py` وارفعوا التغيير، وNetlify ينشره لحاله.

## الأمان والنسخ الاحتياطي

- كل طلب للبيانات لازم يحمل كلمة سر العائلة، والموقع كله على HTTPS.
- السيرفر يحفظ نسخة كل يوم باسم `backup-YYYY-MM-DD` داخل Netlify Blobs.
- من الإعدادات في التطبيق: **نزّل نسخة احتياطية** يحفظ ملف عندكم.

## الاختبار محلياً

```
npm install
node test/server.mjs        # سيرفر على http://localhost:8970 بكلمة سر test-pass-123
```
